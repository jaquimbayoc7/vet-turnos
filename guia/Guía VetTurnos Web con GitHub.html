Construye la recepción de una veterinaria

Vas a crear, paso a paso, una página web en un solo archivo index.html donde se registran perros, gatos y aves. Cada paso agrega un pilar de la POO y deja la página funcionando. Además, aprenderás a crear tu repositorio en GitHub, a subir un commit por cada fase y a cerrar el proyecto con un README. Escribe el código tú mismo; usa el botón de copiar solo si te atascas.
