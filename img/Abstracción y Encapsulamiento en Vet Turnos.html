Abstracción y encapsulamiento en Vet Turnos

El código que dibuja la lista nunca pregunta si el paciente es un perro o un gato: solo conoce el contrato de Mascota. Y nadie puede dejar a una mascota con un peso inválido ni vaciar la lista de pacientes: los datos están protegidos por campos privados.

1. Abstracción: el contrato de Mascota

La clase base no se puede usar sola

new Mascota() falla con TypeError, porque new.target detecta la creación directa.

El contrato obliga a implementar

Si una subclase olvida hacerSonido(), la llamada lanza un Error en vez de devolver algo vacío.

Agregar un animal toca un solo lugar

Una clase nueva que extienda Mascota y una rama en el formulario. dibujar() no cambia.

2. Encapsulamiento: datos privados, acceso controlado

#peso es privado

El prefijo # impide leerlo o escribirlo desde fuera de la clase. Solo get peso y set peso lo tocan.

El setter valida siempre

Tanto en el constructor (this.peso = peso) como en cualquier cambio posterior, un peso no numérico, cero o negativo lanza RangeError.

#pacientes no se expone

registrar() es la única puerta de entrada y el getter devuelve una copia, así que push externo no altera la lista real.

El formulario muestra el error

El try/catch del submit captura el RangeError o el TypeError y lo escribe en #mensaje con la clase error.

Cómo se comporta el código

// El setter protege el campo privado
const p = new Perro("Rex", 12);
p.peso = 15;            // ok: pasa por set peso()
p.peso = -3;            // RangeError: El peso debe ser un número positivo...
p.#peso;                // SyntaxError: fuera de la clase no existe

// La lista de pacientes queda aislada
clinica.registrar(p);
clinica.pacientes.push({});   // solo altera la copia
clinica.pacientes.length;     // sigue siendo 1
clinica.registrar({});        // TypeError: Solo se pueden registrar instancias de Mascota

3. Diagrama de clases

Una jerarquía, una colección

Mascota, Perro y Gato forman la jerarquía. Clinica es independiente y solo conoce el tipo Mascota.

Polimorfismo en hacerSonido()

La misma llamada devuelve "Guau Guau" o "Miau Miau" según la clase concreta, sin condicionales en dibujar().

Lo privado no cruza el borde

Los dos únicos miembros con - son #peso y #pacientes; todo lo demás es la interfaz pública.
