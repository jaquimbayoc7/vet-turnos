Sección 1 de 4Panorama

Tres archivos, tres trabajos

Qué vas a lograr

Reconocer qué responsabilidad tiene cada archivo de VetTurnos y por qué conviene separarlos en lugar de escribir todo en uno solo.

Estructura, aspecto y comportamiento. El HTML dice qué hay en la página (formulario, lista, botón). El CSS dice cómo se ve. El JavaScript dice qué pasa cuando el usuario actúa. Los tres viven en la misma carpeta y el navegador los junta al abrir index.html.

Estructuraindex.html

Define el formulario con sus campos (tipo, nombre, peso), el botón, el mensaje y la lista vacía. Es el único archivo que abres con doble clic.

Aspectoestilos.css

Define los colores verdes, el ancho de la página, el aspecto de las tarjetas de pacientes y los mensajes en verde o rojo.

Comportamientoprograma.js

Contiene las clases Mascota, Perro y Gato, escucha el envío del formulario y dibuja cada paciente en la lista.

    Para pensar: ¿por qué no escribir todo dentro de index.html?

    Qué vas a lograr

    Ver las cuatro conexiones que existen entre los archivos y el orden en que el navegador los lee. Toca un botón y el diagrama resalta la flecha con el código que la hace posible.

    Solo index.html conoce a los otros dos. Dentro de él, <link> trae el CSS y <script> trae el JavaScript. Después los otros dos archivos se refieren al HTML: el CSS mediante selectores y el JavaScript mediante ids.

    Por eso la etiqueta <script> va al final del <body>: cuando programa.js se ejecuta, el formulario y la lista ya existen y getElementById los encuentra.

    Punto de control

      Para pensar: ¿qué pasaría si pones el <script> antes del <form>?

      document.getElementById("formulario") devolvería null porque el formulario todavía no existe, y la línea siguiente lanzaría un error. Hay dos soluciones: dejar el script al final del body, o agregar el atributo defer al script.

      Sección 3 de 4Abstracción

      La abstracción en Mascota

      Qué vas a lograr

      Entender por qué Mascota no se puede crear con new, qué es el contrato hacerSonido() y cómo Perro y Gato lo cumplen. Todas las pruebas de esta sección ejecutan clases reales, escritas igual que en tu programa.js.

      Abstracción: quedarse con lo esencial. En la veterinaria nadie atiende a una «mascota a secas»: llega un perro o un gato. Mascota reúne lo que todas comparten (nombre, peso) y fija un contrato: toda mascota debe saber hacer un sonido, y cada especie decide cuál.

        Para pensar: ¿qué ventaja tiene que Mascota lance un error en vez de dejar hacerSonido() vacío?

        Un método vacío falla en silencio: la mascota «no suena» y nadie sabe por qué. El error obliga a quien crea una clase nueva, como Pez, a completar el contrato, y el mensaje dice exactamente qué falta.

        Sección 4 de 4Revisión

        Revisa tu código

        Qué vas a lograr

        Encontrar y corregir tres detalles de tus archivos. Ninguno impide que la página abra, pero dos afectan lo que el usuario ve y el tercero esconde un mensaje de error roto.

        Un error silencioso es el más difícil de ver. JavaScript y CSS no avisan cuando un nombre no coincide: simplemente no aplican el estilo o devuelven undefined. Revisar las conexiones entre archivos es parte de programar.

        Hallazgo 1

        Afecta lo que se ve

        La clase «Paciente» no coincide con «.paciente»

        En programa.js escribes li.className = "Paciente" con P mayúscula, pero en estilos.css el selector es .paciente en minúscula. CSS distingue mayúsculas, así que las tarjetas de la lista no reciben ningún estilo. Compara las dos con el mismo CSS:

        className = "Paciente"

        • Perro: Rocky - 18 Kg.Guau Guau

        className = "paciente"

        • Perro: Rocky - 18 Kg.Guau Guau

        Hallazgo 2

        Mensaje roto

        this.constructor.nombre devuelve undefined

        Hallazgo 3

        Detalle

        El idioma de la página es «sp»

        En index.html tienes <html lang="sp">. El código de idioma para español es es; «sp» no existe como código válido. El navegador y los lectores de pantalla usan este atributo para pronunciar y traducir bien el contenido.

        Para el siguiente nivel

        Hoy el peso acepta valores como -5, y en estilos.css existe la regla #total sin un elemento con ese id en el HTML. Ambas cosas se resuelven en los pasos de encapsulamiento y polimorfismo de la guía VetTurnos.
